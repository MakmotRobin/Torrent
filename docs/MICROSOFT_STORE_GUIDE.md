# Microsoft Store Publication & Monetization Guide for PulseTorrent

This guide details the complete process for packaging, certifying, publishing, and monetizing **PulseTorrent** on the **Microsoft Store**.

---

## 1. Prerequisites

1. **Microsoft Partner Center Account:**
   * Go to [partner.microsoft.com/dashboard](https://partner.microsoft.com/dashboard).
   * Register as a Windows Developer:
     * **100% Free:** Microsoft permanently eliminated registration fees (previously $19 for individuals / $99 for companies).
     * Account activation uses standard identity verification (ID / selfie for individuals, or business verification for companies) instead of an upfront payment.
2. **Reserve Your App Name:**
   * Inside Partner Center, navigate to **Apps and games** &rarr; **New product** &rarr; **MSIX or PWA app** or **Win32 app**.
   * Reserve the name:
     * **Primary Name:** `PulseTorrent`
     * **Full Store Display Title:** `PulseTorrent - Fast & Modern BitTorrent Client`

## 2. Monetization Strategy: Freemium + PulseTorrent Pro

### Why Freemium is the Optimal Model on Microsoft Store:
* **High Organic Volume:** Free downloads generate 10x-50x more impressions in store search rankings than paid upfront apps.
* **Positive User Ratings:** Core torrent downloading remains completely unrestricted, preventing negative 1-star reviews.
* **High-Converting Pro Tier ($4.99 one-time):** Power users and media enthusiasts willingly pay for:
  * Media preview & instant audio/video streaming while downloading.
  * Bandwidth scheduler (throttling during work hours, full speed off-peak).
  * Custom dark OLED and accent color palettes.
  * Unlimited queue limits and priority swarm allocations.

### Revenue Share:
* **85/15 Split:** Microsoft retains 15% when transactions are processed through Microsoft Store Commerce, and you receive **85%**.
* **100% Developer Split:** If you choose to publish as a Win32 app with your own external web payment provider (Stripe/PayPal), Microsoft allows 0% commission for non-gaming apps.

## 3. Microsoft Store Certification & Regulatory Checklist

To pass Microsoft Certification (Policy 10.2 / 10.5 / 10.8):

* [x] **No Pirated Content Search:** The app does NOT include built-in scrapers or default search engines pointing to pirate indexers.
* [x] **Lawful Use Statement:** The app clearly declares itself as an open-source & authorized P2P transport tool (built into the app's `LegalModal.jsx`).
* [x] **Privacy Policy URL:** Link to `docs/PRIVACY_POLICY.md` (or host it via GitHub Pages: `https://<your-username>.github.io/PulseTorrent/PRIVACY_POLICY.html`).
* [x] **Zero Telemetry / Local Storage:** No user tracking or browsing telemetry is harvested.
* [x] **Windows Defender Compatibility:** The executable must be cleanly signed and free from false-positive heuristics.

## 4. Packaging the Electron App

### Option A: Direct Win32 Listing (Easiest)
Microsoft Store allows developers to submit standard Win32 setup installers (`.exe` or `.msi` generated by `electron-builder` or Inno Setup).
1. Build the production bundle:
   ```bash
   npm run build
   ```
2. Build the Windows installer with `electron-builder`:
   ```bash
   npx electron-builder --win nsis
   ```
3. Upload the resulting installer or provide the direct download URL in Partner Center.

### Option B: MSIX / AppX Store Package
1. Add an `appx` configuration to `package.json` or `electron-builder.yml`:
   ```json
   "build": {
     "appId": "com.pulsetorrent.desktop",
     "productName": "PulseTorrent",
     "win": {
       "target": ["appx"]
     },
     "appx": {
       "identityName": "<Your-Identity-Name-From-Partner-Center>",
       "publisher": "CN=<Your-Publisher-ID>",
       "publisherDisplayName": "<Your Display Name>",
       "applicationId": "PulseTorrent"
     }
   }
   ```
2. Generate the `.appx` / `.msix` file:
   ```bash
   npx electron-builder --win appx
   ```
3. Upload the package directly to the Partner Center package submission step.
